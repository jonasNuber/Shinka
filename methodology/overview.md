# Shinka (進化) — Methodology Overview

## What is Shinka?

**Shinka** is an evolutionary software development framework and philosophy designed for **solo developers and small teams**.

It combines:

- structured thinking
- agile execution
- and strong engineering practices

while remaining **tool-agnostic, lightweight** and **continuously adaptable.**

Shinka does not prescribe rigid processes. Instead, it provides a **coherent structure for thinking, deciding, building, and learning**, allowing a project to evolve deliberately over time.

The name *Shinka* (進化) - originally of japanese origin - means evolution:

not change for its own sake, but intentional, learning-driven growth.
